# Laravel ↔ ASP.NET Core 10: 1-to-1 Map

_Last updated: November 2026_

Almost every Laravel building block has an ASP.NET Core 10 counterpart, but about a third of them come from NuGet libraries rather than the framework itself. Laravel is batteries-included; ASP.NET Core ships the web pipeline, DI, config, auth and EF Core, and leaves queues, mail, events and factories to libraries.

**Versions compared:** Laravel 13 (released March 17, 2026, PHP 8.3–8.5 — [release notes summary](https://benjamincrozat.com/laravel-13)) vs ASP.NET Core 10 on .NET 10 LTS (November 2025) with C# 14 and EF Core 10.

**How to read it:** the quick table gives the mapping at a glance; the code sections show the same thing written both ways (PHP first, C# second); the last three sections cover what does *not* map 1-to-1.

## Quick lookup: Laravel → ASP.NET Core 10

"Built in" means it ships with ASP.NET Core / EF Core; otherwise the usual library is named.

| Area | Laravel / PHP | ASP.NET Core 10 / C# | Built in? |
| --- | --- | --- | --- |
| Entry point | `bootstrap/app.php`, `public/index.php` | `Program.cs` (`WebApplication.CreateBuilder`) | Yes |
| Package manager | Composer (`composer.json`) | NuGet (`.csproj` `<PackageReference>`) | Yes |
| CLI | `php artisan` | `dotnet` CLI + `dotnet ef` | Yes |
| REPL | `php artisan tinker` | C# Interactive (`csi`), LINQPad, `dotnet run app.cs` file-based apps | Partly |
| Routing | `routes/web.php`, `routes/api.php` | Minimal APIs (`app.MapGet`) or attribute routing (`[HttpGet]`) | Yes |
| Route groups | `Route::prefix()->middleware()->group()` | `app.MapGroup("/api").RequireAuthorization()` | Yes |
| Named routes / `route()` | `->name('users.show')`, `route('users.show', $id)` | `.WithName("UsersShow")`, `LinkGenerator` | Yes |
| Route model binding | `function show(User $user)` | No direct equivalent; load in handler or custom `IModelBinder` / `BindAsync` | No |
| Controllers | `Controller` classes | `ControllerBase` + `[ApiController]`, or Minimal API handlers | Yes |
| Middleware | `handle($request, Closure $next)` | `app.Use(...)`, `IMiddleware`, endpoint filters | Yes |
| Service container | `app()->bind / singleton / scoped` | `builder.Services.AddTransient / AddSingleton / AddScoped` | Yes |
| Service providers | `AppServiceProvider::register/boot` | `IServiceCollection` extension methods, called from `Program.cs` | Yes |
| Facades | `Cache::get()`, `Log::info()` | None; inject the interface (`IMemoryCache`, `ILogger<T>`) | No (by design) |
| Config | `config/*.php`, `config('app.name')` | `appsettings.json` + `IOptions<T>` / `IConfiguration` | Yes |
| `.env` | `.env` + `env()` | Environment variables, `appsettings.{Env}.json`, User Secrets | Yes |
| Migrations | `Schema::create(...)` hand-written | `dotnet ef migrations add` generated from model diff | Yes (EF Core) |
| Models (ORM) | Eloquent (Active Record) | EF Core entities + `DbContext` (Unit of Work / Data Mapper) | Yes (EF Core) |
| Relationships | `hasMany`, `belongsTo`, `belongsToMany` | Navigation properties + `HasMany().WithOne()` | Yes |
| Eager loading | `->with('posts')` | `.Include(u => u.Posts)` | Yes |
| Query builder | `DB::table()->where()` | LINQ on `DbSet<T>`, raw SQL via `FromSql` | Yes |
| Raw SQL helper | `DB::select()` | `db.Database.SqlQuery<T>()`, Dapper | Yes / Dapper |
| Local scopes | `scopeActive($q)` | `IQueryable<T>` extension methods | Yes (language) |
| Global scopes / soft deletes | `SoftDeletes` trait, global scopes | `HasQueryFilter` (named filters in EF Core 10) + `SaveChanges` interceptor | Partly |
| Casts / accessors | `$casts`, `Attribute::make()` | Value converters, C# properties | Yes |
| Model events / observers | `creating`, `Observer` classes | `SaveChangesInterceptor`, `ChangeTracker` events | Yes |
| Seeders | `DatabaseSeeder` | `UseSeeding` / `UseAsyncSeeding`, `HasData` | Yes |
| Factories | `User::factory()->count(10)` | Bogus (fake data library) | No — Bogus |
| Pagination | `->paginate(15)` | `.Skip().Take()` manually, or X.PagedList | No |
| Collections | `collect()->map()->filter()` | LINQ (`Select`, `Where`, `GroupBy`) | Yes |
| DTOs | Plain classes / readonly classes, spatie/laravel-data | `record` types | Yes (language) |
| Validation | Form Requests, `$request->validate()` | DataAnnotations + .NET 10 Minimal API validation, or FluentValidation | Partly |
| API Resources | `JsonResource` | DTO projection (`Select` into a record), `System.Text.Json` | Yes |
| Auth (session) | Breeze / Fortify / `Auth::attempt` | ASP.NET Core Identity + cookie auth | Yes |
| API tokens | Sanctum / Passport | JWT bearer, `MapIdentityApi`, OpenIddict / Duende | Partly |
| Passkeys | Laravel 13 passkeys | Identity passkey support (.NET 10) | Yes |
| Gates / policies | `Gate::define`, `Policy` classes | Authorization policies + `IAuthorizationHandler` | Yes |
| Jobs / queues | `ShouldQueue`, `dispatch()`, Horizon | Hangfire, MassTransit, Wolverine; `BackgroundService` + `Channel<T>` | No |
| Scheduler | `Schedule::command()->daily()` | Hangfire recurring jobs, Quartz.NET, `PeriodicTimer` | No |
| Events / listeners | `Event::dispatch`, `Listener` | Wolverine, MediatR, or C# `event`s | No |
| Cache | `Cache::remember()` | `HybridCache`, `IMemoryCache`, `IDistributedCache` | Yes |
| Mail | `Mailable`, `Mail::to()` | MailKit, FluentEmail | No |
| Notifications | `Notification` (mail, SMS, Slack) | No equivalent; compose services | No |
| Broadcasting / WebSockets | Echo + Reverb / Pusher | SignalR (in-process) | Yes |
| Server-Sent Events | `response()->eventStream()` | `TypedResults.ServerSentEvents` (.NET 10) | Yes |
| File storage | `Storage::disk('s3')` | `IFileProvider` local; Azure / AWS SDKs, FluentStorage | Partly |
| Logging | `Log::` (Monolog) | `ILogger<T>`, Serilog | Yes |
| HTTP client | `Http::get()` | `IHttpClientFactory`, Refit | Yes |
| Rate limiting | `RateLimiter::for()` | `AddRateLimiter` middleware | Yes |
| Views | Blade | Razor (MVC views / Razor Pages) | Yes |
| Reactive UI | Livewire | Blazor (Server / WebAssembly) | Yes |
| SPA bridge | Inertia | No official equivalent | No |
| Localization | `__('messages.welcome')` | `IStringLocalizer<T>` + `.resx` | Yes |
| Testing | PHPUnit / Pest, `$this->get()` | xUnit / NUnit + `WebApplicationFactory<T>` | Yes |
| API docs | Scribe / Scramble | `Microsoft.AspNetCore.OpenApi` (OpenAPI 3.1 in .NET 10) | Yes |
| Long-running server | Octane (Swoole / FrankenPHP) | Kestrel (always long-running) | Yes |

## Web layer, side by side

### Project structure

| Laravel | ASP.NET Core 10 (common layout) |
| --- | --- |
| `app/Models` | `Models/` or `Domain/Entities/` |
| `app/Http/Controllers` | `Controllers/` or `Endpoints/` (Minimal APIs) |
| `app/Http/Middleware` | `Middleware/` |
| `app/Http/Requests` | `Validators/` (FluentValidation) or attributes on DTOs |
| `app/Jobs` | `Jobs/` or `Workers/` |
| `app/Providers` | `Extensions/ServiceCollectionExtensions.cs` |
| `database/migrations` | `Migrations/` (generated by `dotnet ef`) |
| `routes/*.php` | `Program.cs` or `Endpoints/*.cs` |
| `config/*.php` + `.env` | `appsettings.json` + `appsettings.Development.json` |
| `resources/views` | `Views/` or `Pages/` |
| `tests/` | separate `MyApp.Tests` project |

### Middleware

```csharp
public class EnsureIsAdmin : IMiddleware
{
    public async Task InvokeAsync(HttpContext ctx, RequestDelegate next)
    {
        if (!ctx.User.IsInRole("Admin")) { ctx.Response.StatusCode = 403; return; }
        await next(ctx);
    }
}
// Program.cs
```

## Data layer, side by side

The core shift: in Laravel you write the migration and the model reads the table; in EF Core you write the model and the migration is generated from it.

### Migrations

**PHP — Laravel 13**

```php
// php artisan make:migration create_posts_table
Schema::create('posts', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->string('title', 200);
    $table->text('body');
    $table->boolean('published')->default(false);
    $table->timestamps();
    $table->softDeletes();
});
// php artisan migrate   |   php artisan migrate:rollback
```

**C# — ASP.NET Core 10 / EF Core 10**

```csharp
// 1. Change the entity / DbContext (see Models below)
// 2. dotnet ef migrations add CreatePosts      → generates Up()/Down() code
// 3. dotnet ef database update                → applies it
// Rollback: dotnet ef database update <PreviousMigrationName>

// Generated migration (you rarely hand-write this)
migrationBuilder.CreateTable(
    name: "Posts",
    columns: t => new {
        Id = t.Column<int>(nullable: false).Annotation("SqlServer:Identity", "1, 1"),
        UserId = t.Column<int>(nullable: false),
        Title = t.Column<string>(maxLength: 200, nullable: false),
        Body = t.Column<string>(nullable: false),
        Published = t.Column<bool>(nullable: false, defaultValue: false),
    },
    constraints: t => t.PrimaryKey("PK_Posts", x => x.Id));
```

### Models

**PHP — Laravel 13**

```php
class Post extends Model
{
    use HasFactory, SoftDeletes;

    protected $fillable = ['title', 'body', 'published'];
    protected $casts = ['published' => 'boolean', 'meta' => 'array'];

    public function user(): BelongsTo { return $this->belongsTo(User::class); }
    public function tags(): BelongsToMany { return $this->belongsToMany(Tag::class); }
}
// Laravel 13 can also configure this with attributes, e.g. #[Table('posts')]
```

**C# — ASP.NET Core 10 / EF Core 10**

```csharp
public class Post
{
    public int Id { get; set; }
    public int UserId { get; set; }
    public User User { get; set; } = null!;              // belongsTo
    public List<Tag> Tags { get; set; } = [];              // belongsToMany (join table auto-created)
    [MaxLength(200)] public required string Title { get; set; }
    public required string Body { get; set; }
    public bool Published { get; set; }
    public PostMeta Meta { get; set; } = new();            // stored as JSON (see Casts)
    public DateTime CreatedAt { get; set; }
    public DateTime? DeletedAt { get; set; }               // soft delete
}

public class AppDbContext(DbContextOptions<AppDbContext> o) : DbContext(o)
{
    public DbSet<Post> Posts => Set<Post>();
    public DbSet<User> Users => Set<User>();

    protected override void OnModelCreating(ModelBuilder b)
    {
        b.Entity<Post>().HasOne(p => p.User).WithMany(u => u.Posts).OnDelete(DeleteBehavior.Cascade);
        b.Entity<Post>().ComplexProperty(p => p.Meta, m => m.ToJson());
        b.Entity<Post>().HasQueryFilter(p => p.DeletedAt == null);   // SoftDeletes global scope
    }
}
```

No `$fillable` needed: mass-assignment protection comes from binding requests to a DTO, never to the entity.

```csharp
public class SlugInterceptor : SaveChangesInterceptor
{
    public override ValueTask<InterceptionResult<int>> SavingChangesAsync(
        DbContextEventData e, InterceptionResult<int> r, CancellationToken ct = default)
    {
        foreach (var entry in e.Context!.ChangeTracker.Entries<Post>().Where(x => x.State == EntityState.Added))
```

**C# — ASP.NET Core 10**

```csharp
// Simple gate = policy

    .AddPolicy("Admin", p => p.RequireRole("Admin"));

// Resource policy = requirement + handler
public class IsOwner : IAuthorizationRequirement;
public class PostOwnerHandler : AuthorizationHandler<IsOwner, Post>
{
    protected override Task HandleRequirementAsync(AuthorizationHandlerContext c, IsOwner r, Post post)
    {
        if (c.User.FindFirstValue(ClaimTypes.NameIdentifier) == post.UserId.ToString()) c.Succeed(r);
        return Task.CompletedTask;
    }
}
// In handler: (await auth.AuthorizeAsync(User, post, new IsOwner())).Succeeded
```

### Jobs and queues

**PHP — Laravel 13**

```php
class SendWelcomeEmail implements ShouldQueue
{
    use Queueable;
    public $tries = 3;
    public function __construct(public User $user) {}
    public function handle(Mailer $mail) { $mail->to($this->user)->send(new Welcome); }
}
SendWelcomeEmail::dispatch($user)->delay(now()->addMinutes(5));
// php artisan queue:work
```

**C# — ASP.NET Core 10**

```csharp
// Hangfire (persistent queue, retries, dashboard ≈ Horizon)
public class WelcomeEmailJob(IEmailSender mail)
{
    [AutomaticRetry(Attempts = 3)]
    public Task Handle(int userId) => mail.SendWelcomeAsync(userId);
}
BackgroundJob.Schedule<WelcomeEmailJob>(j => j.Handle(user.Id), TimeSpan.FromMinutes(5));

// Built-in, in-memory only (lost on restart): BackgroundService + Channel<T>
public class EmailWorker(Channel<int> queue, IServiceScopeFactory scopes) : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken ct)
    {
        await foreach (var userId in queue.Reader.ReadAllAsync(ct))
        {
            using var scope = scopes.CreateScope();
            await scope.ServiceProvider.GetRequiredService<IEmailSender>().SendWelcomeAsync(userId);
        }
    }
}
```

The worker runs inside the web process — no separate `queue:work` command needed.

## Not 1-to-1: what PHP / Laravel can do that C# can't

PHP's edge is runtime dynamism: methods, properties and classes can be invented or resolved while the code runs. Each item shows the PHP feature, then the closest C# you'd actually write.

### 1. Magic methods: methods that don't exist until called

**PHP — Laravel 13**

```php
class User extends Model {}

User::whereEmail('a@b.com')->first();   // no whereEmail method exists — __callStatic builds it
$user->posts;                            // no posts property exists — __get loads the relationship
```

**C# — ASP.NET Core 10 (closest equivalent)**

```csharp
// Every member must exist at compile time; you spell the query out.
var user = await db.Users.FirstOrDefaultAsync(u => u.Email == "a@b.com");
var posts = user!.Posts;   // a real navigation property, declared on the class
```

### 2. Facades: static calls to swappable instances

**PHP — Laravel 13**

```php
Cache::put('k', 'v');                           // static syntax, container-resolved instance
Cache::shouldReceive('get')->andReturn('fake'); // mock it in a test
```

**C# — ASP.NET Core 10 (closest equivalent)**

```csharp
// Statics can't be swapped or mocked, so you inject the interface.
public class StatsService(IMemoryCache cache)
{
    public void Save() => cache.Set("k", "v");
}
// Test: new StatsService(new FakeCache())  or a mock via Moq / NSubstitute
```

### 3. Macros: add methods to classes at runtime

**PHP — Laravel 13**

```php
Collection::macro('toUpper', fn () => $this->map(fn ($v) => strtoupper($v)));

```

**C# — ASP.NET Core 10 (closest equivalent)**

```csharp
// Compile-time only: can't be added or removed based on runtime config.

{
    public static IEnumerable<string> ToUpper(this IEnumerable<string> s) => s.Select(v => v.ToUpper());
}
new[] { "a", "b" }.ToUpper();
```

### 4. Strings as class and method names

**PHP — Laravel 13**

```php

$method = 'export' . ucfirst($format);
$report->$method();   // exportPdf(), exportCsv()…
```

**C# — ASP.NET Core 10 (closest equivalent)**

```csharp

// What C# devs actually do: a keyed DI lookup

```

### 5. Late static binding on inherited static methods

**PHP — Laravel 13**

```php

```

**C# — ASP.NET Core 10 (closest equivalent)**

```csharp

{
    static abstract TSelf Create(Dictionary<string, object> a);
}
public class User : ICreatable<User> { public static User Create(Dictionary<string, object> a) => new(); }
static T Make<T>(Dictionary<string, object> a) where T : ICreatable<T> => T.Create(a);
```

## Gotchas when switching

Most bugs in a Laravel → .NET move come from three things: the long-lived process, the change tracker, and async.

| Gotcha | Laravel habit | What to do in ASP.NET Core 10 |
| --- | --- | --- |
| Service lifetimes | Everything is fresh per request | Never inject a scoped service (e.g. `DbContext`) into a singleton; use `IServiceScopeFactory` |
| `DbContext` is not thread-safe | One DB connection per request, no concurrency | Don't run two queries on the same `DbContext` in `Task.WhenAll`; use `IDbContextFactory` |
| Saving | `$model->save()` writes now | Nothing is written until `SaveChangesAsync()` |
| Read-only queries | Eloquent returns plain models | Add `.AsNoTracking()` or project with `Select` to skip tracking overhead |
| N+1 queries | `with('posts')` | `.Include(p => p.Posts)`; lazy loading is off by default (good) |
| Migrations | Hand-write the schema | Change the C# model, then generate; review the generated file |
| Mass assignment | `$fillable` / `$guarded` | Bind requests to DTOs, never to entities |
| Async everywhere | Code is synchronous | Use `async`/`await` end to end; never `.Result` or `.Wait()` (deadlocks, thread starvation) |
| Static state | Resets every request | Lives until the app restarts; avoid mutable statics |
| Global helpers | `auth()`, `request()`, `config()` anywhere | Inject `IHttpContextAccessor`, `IOptions<T>`, etc. |
| Nulls | `$user?->name` at runtime | Turn on nullable reference types and treat warnings as errors |
| Deploys | Push files, done | `dotnet publish`, then restart the app or container |
| Queues and schedules | `queue:work` + cron | Hangfire / hosted services inside the app, or a separate worker project |
